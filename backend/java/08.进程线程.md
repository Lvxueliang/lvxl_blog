# 并发
并发： 同一时刻，多个任务交替执行，造成一种“貌似同时”的效果。 简单的说，单核cpu实现的多任务就是并发

# 并行
并行： 同一时间，多个任务同时执行，多核cpu实现的多任务就是并行


# Runnable 接口
Runnable 接口是一个接口，它只有一个方法 run()，用于定义线程的执行内容。
```java
Dog dog = new Dog();
Thread thread = new Thread(dog);
thread.start(); // 启动线程


class Dog implements Runnable {
  int count = 0;
  @Override
  public void run() {
    while (true) {
      System.out.println("狗在吃屎" + (++count) + Thread.currentThread().getName());
      try {
        Thread.sleep(1000);
      } catch (InterruptedException e) {
        throw new RuntimeException(e);
      }
      System.out.println("狗吃屎结束" + Thread.currentThread().getName());
    }
  }
}
```

# 线程使用 thread 类  
1. 当一个类继承了thread类，就可以创建一个线程
2. 一般重写run方法，来实现线程的执行内容
3. run thread的方法是重写 runnable 接口的 run 方法
4. yield() 方法： 用于让出当前线程的执行机会，使其他线程有机会执行
5. join() 方法： 线程插队，插队的线程一旦插入成功，肯定先执行插入的线程所有任务。
```java
Cat cat = new Cat();
cat.start(); // 启动线程

class Cat extends Thread {
  @Override
  public void run() {

    System.out.println("猫在吃鱼" + Thread.currentThread().getName());

    try {
      Thread.sleep(1000);
    } catch (InterruptedException e) {
      throw new RuntimeException(e);
    }
    System.out.println("猫吃鱼结束" + Thread.currentThread().getName());
  }
}
```

## 线程终止
interrupt() 方法： 用于中断线程的执行，使线程进入中断状态。

```java
ti = new T();
ti.start(); // 启动线程

Thread.sleep(3000); // 等待3秒
ti.setLoop(false); // 终止线程

class T extends Thread {
  private boolean loop = true;

  @Override
  public void run() {
    while (loop) {
      System.out.println("线程在运行" + Thread.currentThread().getName());
    }
  }

  public void setLoop(boolean loop) {
    this.loop = loop;
  }
}
```

## 用户线程 和 守护线程
1. 用户线程： 也叫工作线程， 当线程的任务执行完成或通知方式结束
2. 守护线程： 也叫后台线程， 当所有用户线程都终止时，守护线程也会被终止。
3. 常用守护线程： 垃圾回收机制


## 线程的生命周期
```java
public static enum Thread.State extends Enum<Thread.State> 
```
线程状态：
1. NEW: 尚未启动的线程处于此状态；
2. RUNNABLE: 在java虚拟机中执行的线程处于此状态； ready 状态  running 状态的线程在执行时，会切换到 running 状态，执行完成后，会切换到 ready 状态，等待被调度器调度
3. BLOCKED: 线程被阻塞，等待其他线程释放锁；
4. WAITING: 线程等待指定的时间或直到其他线程通知；
5. TIMED_WAITING: 线程等待指定的时间；
6. TERMINATED: 线程已终止，等待回收资源；


## synchronized 关键字
线程同步机制
1. 在多线程编程，一些敏感数据不允许被多个线程同时访问， 此时就要使用同步访问技术，保证数据在任何统一时刻，最多有一个线程访问，以保证数据完整性。
2. 也可以理解：线程同步，当一个线程在对内存进行操作是，其他线程下都不可以对这个内存地址进行操作，直到该线程完成操作，其他线程才能对该内存地址进行操作。

```java
// 同步代码块
synchronized (对象) {
  // 代码块
}

public synchronized void method() {
  // 代码块
}
```

## 释放锁
1. 当线程同步方法，同步代码块执行完成后，会自动释放锁。
2. 当线程在同步代码块，同步方法中遇到 break，return，也会释放锁。
3. 当线程下在同步代码块，同步方法中出现了Error或者Exception，导致异常结束，也会释放锁。
4. 当线程在同步代码块，同步方法中执行了线程对下的wait()方法， 当前线程暂停，并释放锁。
