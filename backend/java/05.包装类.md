### String

- String对象用于保存字符串，也就一组字符序列
- 字符串的字符使用“Unicode”字符编码，一个字符（不区分字母还是汉字）占两个字节
- String 类有很多构造器， 构造器的重载
  - String s1 = new String()
  - String s2 = new String(char[] a);
  - String s3 = new String(char[] a, int startIndex, int count)
  - String s4 = new String(String original)
  - String s5 = new String(byte[] b)
- String 类实现了接口 Serializable (String 可以串行化： 可以在网络传输)
- ---------------------接口 Comparable (String 对象可以比较大小)
- String 是个final类 不可被继承
- String 有属性 private final char value[]; 用于存放字符串内容
- 一定要注意：value 是个final类型， 不可以修改 （指的是地址不可以改）

```java
Strings s = "lvxl";

// 先从常量池中查找是否有lvxl的数据空间， 如果有， 直接指向， 如果没有则重新创建， 并指向

String s2 = new String("lvxl");
// 先在堆中创建空间，里面维护了了value属性，指向常量池中的lvxl， 如果常量池中没有lvxl，重新创建，如果有， 通过value指向，最终指向的是堆中的空间地址


String a = "abc";
String b = "abc";
System.out.println(a.equals(b)); // true
System.out.println(a == b); // true
```

# StringBuffer

1. stringBuffer的直接父类是AbstractStringBuilder
2. StringBuffer 实现了 Srializable ，即StringBuffer的对象可以串行化
3. 在父类中， AbstractStringBuilder 有属性 char[] value, 不是final; 该value数组存放 字符串内容， 引出存放在堆中的
4. StringBuffer 是一个final类， 不能被继承
5. StringBuffer字符串内容存在char[] value， 所有在变化 （add/delete）；不用每次豆更换地址（即不是每次豆创建新对象） ， 所以效率高于String

```java
// 1. 创建一个 大小为 16的 char数组 value
StringBuffer sb = new StringBuffer();
// 2. 通过构造器指定 char[] 大小
StringBuffer sb2 = new StringBuffer(100);
// 3. 通过给一个String 创建 StringBuffer , char[] 大小就是 str.length() + 16
StringBuffer sb3 = new StringBuffer("lvxl");
```

#### StringBuffer 类型转换
```java
// String -> StringBuffer
String str = "hello world";
// 1. 通过构造器将String 转换为 StringBuffer
StringBuffer sb = new StringBuffer(str);
// 2. 通过toString方法将StringBuffer 转换为String
StringBuffer sb2 = new StringBuffer();
sb2.append(str);


// StringBuffer -> String
// 1.
String s2 = sb.toString();
// 2.
String s3 = new String(sb);
```

#### StringBuffer方法
1. append(String str) ： 将字符串str追加到当前Buffer的末尾
2. insert(int offset, String str) ： 将字符串str插入到当前Buffer的指定位置
3. delete(int start, int end) ： 删除当前Buffer中从start到end的字符 （不包含end）
4. reverse() ： 反转当前Buffer中的字符
5. replace(int start, int end, String str) ： 替换当前Buffer中从start到end的字符 （不包含end）为字符串str
6. indexOf(String str) ： 返回找字符串str在当前Buffer中的第一个出现位置 如果找不到返回-1
7. length() ： 返回当前Buffer的长度



# StringBuilder
1. 一个可变的字符串序列,此类提供一个与StringBuffer兼容的Api， 但不保证同步安全， `用在字符串缓冲区被单线程使用的时候`，如果可能，优先使用StringBuilder，大多数现实中， StringBuilder的效率高于StringBuffer。
2. StringBuilder上的主要操作是append 和 insert 方法，可以重载这些方法，以接受任意类型的数据；
3. 实现了 Serializable 接口，即 StringBuilder 的对象可以串行化；
4. 是一个final类， 不能被继承
5. 对象字符序列荏苒是存放在其父类AbstractStringBuilder 中的 char[] value 中
6. 没有做互斥处理， 即没有 synchronized 关键字, 因此在单线程环境下使用， StringBuilder 是一个效率较高的选择。



### String StringBuilder StringBuffer 的选择
1. 如果字符串存在大量的修改操作，一般使用StringBuffer 或 StringBuilder
2. 如果字符串存在大量的修改操作，并在单线程环境下使用，一般使用StringBuilder
3. 如果字符串存在大量的修改操作，并在多线程环境下使用，一般使用StringBuffer
4. 如果字符串很少修改，被多个对象引用，使用String， 比如配置信息等


# Arrays 类

### Arrays方法
1. Arrays.toString(arr) ： 将数组转换为字符串
2. Arrays.sort(arr) ： 对数组进行排序
3. Arrays.sort(arr, Comparator) ： 对数组进行排序， 并指定排序规则
4. Arrays.binarySearch(arr, value) ： 对数组进行二分查找， 返回值为索引, 如果找不到返回-1 ,数组必须有序
5. Arrays.copyOf(arr, newLength) ： 复制数组， 并指定新的长度, 返回值为新数组
6. Arrays.fill(arr, value) ： 填充数组， 并指定填充值
7. Arrays.equals(arr1, arr2) ： 对比两个数组是否相等， 返回值为boolean类型 
8. Arrays.asList(arr) ： 将数组转换为List集合， 返回值为List类型
