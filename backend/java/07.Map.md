# Map集合 双列集合
常用方法
1. put  添加元素
2. get  取出元素
3. remove  删除元素
4. size  获取元素个数
5. isEmpty  判断是否为空
6. clear  清空元素

遍历方式
1. containsKey  判断是否包含key
    ```java
    Map map = new HashMap<>();
    Set keySet = map.keySet();
    for(Object key : keySet){
        System.out.println(key + " " + map.get(key));
    }
    // 迭代器遍历keySet
    Iterator it = keySet.iterator();
    while(it.hasNext()){
        Object key = it.next();
        System.out.println(key + " " + map.get(key));
    }

    // 取出所有values
    Collection values = map.values();
    for(Object value : values){
        System.out.println(value);
    }
    
    // entrySet  获取所有key-value对
    Set entrySet = map.entrySet();
    for(Object entry : entrySet){
       // 将entry 转成 Map.entry
        Map.Entry m = (Map.Entry) entry;
        System.out.println(m.getKey() + " " + m.getValue());
    }
    Iterator it2 = entrySet.iterator();
    while(it2.hasNext()){
        Object entry = it2.next();
        Map.Entry m2 = (Map.Entry) entry;
        System.out.println(m2.getKey() + " " + m2.getValue());
    }
    ```

   ## HashMap
   1. 底层数组+链表+红黑树
   2. map用于保存具有映射关系的数据，每个元素都是一个key-value对。
   3. key不能重复，value可以重复。 当有相同的key时，会覆盖之前的value。
   4. key可以null，value也可以为null。 key为null时，只能有一个。
   5. 与hashset一样， 不保证元素的顺序。因为底层是以hash表的方式来存储的
   6. 没有实现同步， 因此是线程不安全的
   #### LinkedHashMap

   ## TreeMap
   ## Hashtable
   1. 键值都不能为null， 否则抛出NullPointerException
   2. 与hashmap不同， 是线程安全的
   #### Properties
   1.可以用于 从xxx.properties文件中读取数据,并进行修改
1. Map集合中是无序的(添加顺序 取出顺序不一致)，且可以重复
2. Map集合每个元素都没有索引，不支持索引取出；


### 小结

1. 先判单存储的类型 （一组对象或一组键值对）
2. 一组对象[单列]: Collection接口
      允许重复： List
          增删多： LinkedList [底层维护了一个双向链表]
          改查多： ArrayList [底层维护了Object类型的可变数组]
      不允许重复： Set
          无序： HashSet [底层维护了一个hash表]
          排序： TreeSet 
          插入和取出顺序一致： LinkedHashSet， [维护数组+双向链表]
3. 一组键值对： Map
      键无序： HashMap
      键排序： TreeMap
      插入和取出顺序一致： LinkedHashMap
      读取文件： Properties
