#  Collection 单列集合

### Collection接口实现类的特点

```java
public interface Collection <E> extends Iterable <E>
```

1. collection实现自类可以存放多个元素，每个元素可以是object
2. 有些Collection的实现类，可以存放重复的元素，有些不可以
3. 有些Collection的实现类，有些是有序的（List），有些不是有序（Set）
4. Collection接口没有直接的实现子类，是通过它的子接口Set和List来实现的

Collection接口常用方法，以子类ArrayList来演示。

1. add  添加单个元素
2. remove  删除单个元素，如果有返回删除对象， 没有返回false;
3. contains 查找元素存不存在 返回boolean
4. size 获取元素个数
5. isEmpty 判断是否为空
6. clear 清空
7. addAll  添加多个元素
8. containsAll  查�断是否包含多个元素
9. removeAll  删除多个元素


### Iterator迭代器
Iterator迭代器是一个接口，用于遍历集合中的元素。
```java
public interface Iterator <E>
```
1. hasNext  判断是否有下一个元素
2. next  取出下一个元素
3. remove  删除当前元素

```java
Collection col = new ArrayList<>();
col.add(new Book(1));
col.add(new Book(2));
col.add(new Book(3));

Iterator it = col.iterator();
while(it.hasNext()){
   Object obj = it.next();
   System.out.println(obj);
}
```
增强for循环遍历集合中的元素
```java
for(Book obj : col){
   System.out.println(obj);
}
```
普通for循环遍历集合中的元素
```java
for(int i = 0; i < col.size(); i++){
   System.out.println(col.get(i));
}
```


### List 有序集合
1. List集合中是有序的(添加顺序 取出顺序一致)，且可以重复
2. List集合每个元素都有索引，支持索引取出；
3. List集合中可以使用索引来访问元素，也可以使用for循环来遍历元素。
   #### ArrayList
   1. ArrayList基本等同与 Vector, 除了 ArrayList 是线程不安全的（执行效率高），在多线程情况下，不建议使用。
   #### LinkedList
   1. LinkedList 是一个双向链表，每个元素都有前一个和后一个元素的引用针。
   2. LinkedList 是线程不安全的，执行效率高。
   3. 维护了两个属性first和last，分别指向首尾节点，
   4. 每个节点（Node），里面又维护了prev，next，item三个属性。其中prev指向前一个节点，next指向后一个节点，item存储元素。
   5. 所以LinkedList的元素添加和删除，相对来说效率要高。
   #### Vector
   1. Vector 是一个有序的数组，每个元素都有索引。
   2. Vector 是线程安全的，执行效率低。
