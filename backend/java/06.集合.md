#  Collection 单列集合

### Collection接口实现类的特点

```java
public interface Collection <E> extends Iterable <E>
```

1. collection实现自类可以存放多个元素，每个元素可以是object
2. 有些Collection的实现类，可以存放重复的元素，有些不可以
3. 有些Collection的实现类，有些是有序的（List），有些不是有序（Set）
4. Collection接口没有直接的实现子类，是通过它的子接口Set和List来实现的

Collection接口常用方法，以子类ArrayList来演示。

1. add  添加单个元素
2. remove  删除单个元素，如果有返回删除对象， 没有返回false;
3. contains 查找元素存不存在 返回boolean
4. size 获取元素个数
5. isEmpty 判断是否为空
6. clear 清空
7. addAll  添加多个元素
8. containsAll  查�断是否包含多个元素
9. removeAll  删除多个元素


### Iterator迭代器
Iterator迭代器是一个接口，用于遍历集合中的元素。
```java
public interface Iterator <E>
```
1. hasNext  判断是否有下一个元素
2. next  取出下一个元素
3. remove  删除当前元素

```java
Collection col = new ArrayList<>();
col.add(new Book(1));
col.add(new Book(2));
col.add(new Book(3));

Iterator it = col.iterator();
while(it.hasNext()){
   Object obj = it.next();
   System.out.println(obj);
}
```
增强for循环遍历集合中的元素
```java
for(Book obj : col){
   System.out.println(obj);
}
```
普通for循环遍历集合中的元素
```java
for(int i = 0; i < col.size(); i++){
   System.out.println(col.get(i));
}
```


### List 有序集合
1. List集合中是有序的(添加顺序 取出顺序一致)，且可以重复
2. List集合每个元素都有索引，支持索引取出；
3. List集合中可以使用索引来访问元素，也可以使用for循环来遍历元素。
   #### ArrayList
   1. ArrayList基本等同与 Vector, 除了 ArrayList 是线程不安全的（执行效率高），在多线程情况下，不建议使用。
   #### LinkedList
   1. LinkedList 是一个双向链表，每个元素都有前一个和后一个元素的引用针。
   2. LinkedList 是线程不安全的，执行效率高。
   3. 维护了两个属性first和last，分别指向首尾节点，
   4. 每个节点（Node），里面又维护了prev，next，item三个属性。其中prev指向前一个节点，next指向后一个节点，item存储元素。
   5. 所以LinkedList的元素添加和删除，相对来说效率要高。
   #### Vector
   1. Vector 是一个有序的数组，每个元素都有索引。
   2. Vector 是线程安全的，执行效率低。











### Set 无序集合
1. Set集合中是无序的(添加顺序 取出顺序不一致)，且不可以重复
2. Set集合每个元素都没有索引，不支持索引取出；

常用方法： 
   1. size() 获取元素个数
   2. isEmpty() 判断是否为空
   3. clear() 清空集合
   4. add() 添加元素
   5. remove() 删除元素
   6. contains() 查找元素存不存在 返回boolean
   7. containsAll() 查找是否包含多个元素
   8. removeAll() 删除多个元素
   9. equals() 判断是否相等 返回boolean

   #### HashSet
   1. 实现了HashSet接口，是一个无序的集合，不可以重复重复的元素。
   2. HashSet 实际上是一个HashMap，只是HashMap的key是元素，value是null。
   3. 可以存放null值，但是只能存放一个null值。
   4. 不能保证元素是有序的，取决于hash后，在确定索引的结果
   5. 不能有重复的元素/对象

   底层机制说明：
   1. 添加一个元素是，先得到hash值，根据hash值，确定元素的索引。
   2. 找到存储数据表tabel，看到这个索引位置是否已经存放元素。
   3. 如果没有，直接加入
   4. 如果元素已经存在， 调用equals方法判断是否是同一个对象。如果相同，就放弃添加，不同，则添加到最后。
   5. java8中，如果链表元素个数超过_THRESHOLD（默认值为8），就会将链表转换为红黑树。

# Collections 集合工具类
1. reverse()  反转集合的元素顺序
2. shuffle()  随机打乱集合的元素顺序
3. sort()  对集合的元素进行排序
4. swap()  交换集合中两个元素的位置
5. max()  返回集合中最大的元素
6. min()  返回集合中最小的元素
7. copyOf()  复制一个集合
8. frequency()  返回集合中元素出现的次数
9. replaceAll()  替换集合中所有的元素
