# IO流

## 文件 File
1. new File(String pathname) // 根据路径名创建文件对象
2. new File(String parent, String child) // 根据父路径名和子路径名创建文件对象
3. new File(File parent, String child) // 根据父文件和子路径名创建文件对象

```java
// 方法1
File file = new File("src/main/resources/01.txt");
file.createNewFile();
// 方法2
String parent = "e:\\";
String fileName = "01.txt";
File file = new File(parent, fileName);
file.createNewFile();


// 方法3
File parent = new File("e:\\");
File child = new File(parent, "01.txt");
child.createNewFile();
```
`method`:
1. file.getName() // 获取文件名
2. file.getAbsolutePath() // 获取绝对路径
3. file.getParent() // 获取父路径
4. file.length() // 获取文件大小（字节）
5. file.exists() // 判断文件是否存在
6. file.isDirectory() // 判断文件是否是目录
7. file.isFile() // 判断文件是否是文件

## 目录
mkdir创建一级目录
mkdirs创建多级目录
delete删除目录或文件

## 输入流

### InputStream 字节输入流
1. FileInputStream: 文件输入流
2. FilterInputSteam => BufferedInputStream: 缓冲输入流
3. ObjectInputStream: 对象输入流
### Reader
1. InputStreamReader: 字符输入流
2. FileReader: 文件字符输入流



## 输出流
### OutputStream
1. FileOutputStream: 文件输出流
### Writer
1. FileWriter: 文件字符输出流
   - write(int c) // 写入一个字符
   - write(String str) // 写入一个字符串
   - write(char[] cbuf, int off, int len) // 写入一个字符数组
   - write(char[] cbuf) // 写入一个字符数组
   - write(String str, int off, int len) // 写入一个字符串
   - write(String str) // 写入一个字符串
